# JEV monthly cost estimate: article-to-dataset relevance screening

I couldn't open the linked page, so this uses only the pricing you gave: **$0.042 per million input tokens, output free**. The token counts are my estimates, and the main assumption is flagged below.

## 1. Assumptions

| Parameter | Value |
|---|---|
| Articles per week | 5,000 |
| Average article length | 6,000 visible characters (about 900–1,000 words) |
| Characters per token (English prose) | about 4 |
| **Tokens per article** | **about 1,500** (range 1,300–1,500; 1,000 words × 1.3 ≈ 1,300) |
| Weeks per month | 52 ÷ 12 ≈ 4.33 |
| Output tokens | Free, so $0 |

## 2. Cost per token

- $42 per 1,000,000,000 tokens = **$0.000000042 per input token** (4.2 × 10⁻⁸)
- $0.042 per 1,000,000 tokens = **$0.000042 per 1,000 tokens**

## 3. Baseline calculation (article text only)

| Metric | Tokens | Cost |

**Main uncertainty:** I don't know whether JEV needs the dataset definition or labels sent with each article. If it does, those tokens are billed as input on every call, which is the "with dataset description" row above.

## 5. Other relevant metrics

- **Monthly volume:** about 21,700 articles and 32.5M input tokens.
- **Output cost:** $0, so the cost is predictable and scales only with input length.
- **Scaling:** 10× the volume (50,000 articles per week) would cost about $13.65 per month at baseline. Even 100× would be about $137.
- **Cost per correctly tagged "evidence" article:** this depends on your hit rate. If 5% of articles qualify (about 1,083 per month), the screening cost is roughly **$0.0013 per positive article**.
- **Tokenizer variance:** non-English text, heavy punctuation or URLs can raise token counts by 20–100%. Even doubling would only bring the baseline to about $2.73 per month.

## 6. Costs not covered by JEV pricing

- Crawling or monitoring infrastructure and article extraction.
- Storage and a database for results.
- Human review of borderline cases. This is likely to be the dominant cost, since JEV screening costs only about $1–10 per month.
- Any separate LLM step, for example extracting structured fields (seizure quantity, location) from the articles that pass the filter.

## Bottom line

At 5,000 articles per week, JEV would cost about **$1.40 per month** (about $0.32 per week) in the baseline case, and roughly **$1–$9 per month** across reasonable scenarios, including checking each article against several datasets. The cost is negligible, so the decision should rest on classification accuracy, false-negative rates and integration effort.
