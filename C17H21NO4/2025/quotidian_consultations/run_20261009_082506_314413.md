# Monthly cost estimate: JEV for article-to-dataset classification

I couldn't open the linked page, so this uses the pricing you gave: **$0.042 per million input tokens, output free**. Token counts are my assumptions, and the tokenizer JEV uses may differ.

## 1. Unit pricing

| Unit | Cost |
|---|---|
| Per million input tokens | $0.042 |
| Per thousand input tokens | $0.000042 |
| Per single token | $0.000000042 (4.2 × 10⁻⁸) |
| Output tokens | $0 |

## 2. Token assumptions per article

- 6,000 visible characters ÷ ~4 characters per token (typical for English) ≈ **1,500 tokens**.
- Dataset context (definition, e.g. "seizures of product X", plus the label options such as evidence / not evidence / other) ≈ **300 tokens**. This is added to each call and may be smaller or larger depending on how JEV takes dataset definitions.
- **Base case: ~1,800 input tokens per article.**

The output is a label, which costs nothing.

## 3. Volume

- 5,000 articles per week
- Monthly volume: 5,000 × 52 ÷ 12 ≈ **21,667 articles**

## 4. Base-case breakdown

| Metric | Value |

| Tokens per article | 1,800 |
| Cost per article | ≈ $0.0000756 |
| Cost per 1,000 articles | ≈ $0.076 |

| **Cost per week** | **≈ $0.38** |

## 5. Sensitivity scenarios

| Scenario | Tokens per article | Tokens per month | Monthly cost |
|---|---|---|---|
| Lean (5 chars per token, no extra context) | 1,200 | 26 M | ≈ $1.09 |
| Article text only (4 chars per token) | 1,500 | 32.5 M | ≈ $1.37 |
| **Base (text + 300-token context)** | **1,800** | **39 M** | **≈ $1.64** |
| Heavy (3.5 chars per token + 500-token context) | ~2,250 | 48.75 M | ≈ $2.05 |
| Raw HTML sent instead of visible text (~20k tokens) | 20,000 | 433 M | ≈ $18.20 |

Realistic range: **about $1 to $2 per month**. Sending raw HTML is the main way to go meaningfully higher, so strip the markup before sending.

## 6. Scaling factors

- **Multiple datasets:** If each article is checked against N datasets in separate calls, cost scales linearly. At 10 datasets, the base case is about $16.40 per month. If JEV can score several datasets or labels in one pass, it is much cheaper.
- **Long articles:** Cost is proportional to length. A 12,000-character article costs about twice as much.
- **Cost relative to LLMs:** At $0.042 per MTok, JEV is about 24 times cheaper on input than a model priced at $1 per MTok, and output is free. An LLM would also charge for output tokens.

## 7. Costs not included

- Scraping, crawling, and article extraction (including boilerplate removal)
- Storage and database costs
- Human review of borderline classifications
- Any minimum fees, rate-limit tiers, or enterprise pricing on JEV's side, which I couldn't check
- Re-processing costs if you re-run articles when a dataset definition changes (each full re-run of a month's articles costs about $1.64 in the base case)

## Bottom line

Classifying 5,000 articles per week with JEV costs about **$0.38 per week, or about $1.64 per month** (39 million input tokens, free output), with a realistic range of $1 to $2. At this price, the cost of the classification itself is negligible, and scraping, infrastructure, and review will likely dominate your budget.
