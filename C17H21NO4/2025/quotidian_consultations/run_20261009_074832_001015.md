# Monthly cost estimate: JEV for article-to-dataset classification

I haven't opened the linked page, so this uses the pricing you gave: **$0.042 per million input tokens, output free**. The token counts are my assumptions, since I don't know JEV's tokenizer.

## 1. Assumptions

| Item | Value | Note |
|---|---|---|
| Articles per week | 5,000 | Given |
| Avg. article length | 6,000 characters (~900–1,000 words) | Given |
| Chars per token | ~4 | Typical English rule of thumb |
| **Article tokens** | **~1,500** | 6,000 ÷ 4 |
| Dataset context per request | ~300 | Assumed: dataset definition, e.g. "tracking seizures of product X", plus label options such as evidence / not evidence / other |
| **Input tokens per article (base)** | **~1,800** | 1,500 + 300 |

## 2. Cost per token and per article

## 4. Sensitivity

| Scenario | Tokens/article | Weekly tokens | Weekly cost | Monthly cost |
|---|---|---|---|---|
| Low (dense tokenizer, no extra context) | 1,300 | 6.5 M | $0.27 | **$1.18** |

Even the high case is about $2.30 per month.

## 5. Scaling factors

Cost scales linearly with the number of datasets each article is checked against.

| Datasets checked per article | Monthly cost (base) |
|---|---|
| 1 | $1.64 |
| 5 | $8.19 |
| 10 | $16.38 |
| 50 | $81.90 |

Other things that change the number:
- **Volume:** 10× the articles (50,000 per week) is about $16 per month for one dataset.
- **Non-English text:** tokenizers are often less efficient, so token counts may be 1.5–3× higher.
- **Long reports:** a 50-page PDF at about 30,000 tokens costs about $0.00126 each.
- **Re-runs:** reclassifying the archive after changing a dataset definition is a one-off cost of the same size. For example, 1M archived articles is about $75.

## 6. Decision-relevant takeaways

- Cost is negligible: about **$1.64 per month**, or about $20 per year, for 5,000 articles per week.
- Because output is free, you can request richer output (labels, confidence scores, rationales) at no added cost, if JEV supports it.
- For comparison, a general LLM doing the same job would charge for both input and output. At illustrative rates of $0.10–$3 per million input tokens, the same volume would cost roughly $4–$120 per month before output tokens. Check current prices before relying on this.
- At this scale, the cost that matters is human review of borderline cases, and engineering and integration time, not inference.

## 7. Things to verify

- JEV's actual tokenizer, by running a few sample articles.
- Any minimum charges, rate limits, or subscription fees beyond per-token pricing.
- Whether the dataset context must be resent with every request, or can be cached or built into the model.
- The model's accuracy on your "evidence" classification, since the cost savings only matter if precision and recall are good enough.
