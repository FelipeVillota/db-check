# Monthly cost estimate: JEV for article-to-dataset classification

I couldn't open the blog post, so this uses the pricing you gave: **$0.042 per million input tokens** and **free output**. The token counts are my own assumptions, and you should replace them with real tokenizer counts.

## 1. Unit pricing

| Item | Price |
|---|---|
| Input | $0.042 / 1M tokens = **$0.000000042 per token** |
| Output | $0 |
| Per 1,000 input tokens | $0.000042 |

## 2. Assumptions

- **Volume:** 5,000 articles/week × 52 ÷ 12 ≈ **21,667 articles/month**
- **Article size:** 6,000 characters ÷ ~4 chars/token ≈ **1,500 tokens**. The range is 1,300–1,800 depending on the tokenizer and on language, URLs and boilerplate.
- **Per-request overhead:** the dataset definition, such as "evidence of seizures of product X" plus the label options (evidence / not evidence / other), is roughly **300 tokens**. If JEV lets you configure this once, the overhead may be lower.
- **Total input per article:** ~1,800 tokens
- **Output:** a label or score, with no cost impact

## 5. Scaling with multiple datasets

If each article is checked against several datasets (seizures, sanctions, recalls and so on) as separate calls, cost scales linearly:

| Datasets per article | Monthly cost (base) |
|---|---|
| 1 | $1.64 |
| 5 | $8.19 |
| 10 | $16.38 |
| 50 | $81.90 |

Even at 50 datasets, the cost is small.

## 6. Rough comparison with an LLM

As an illustration only, take a small LLM at about $0.15/M input and $0.60/M output, with ~50 output tokens per article. That comes to about $5.85 for input plus $0.65 for output, or **~$6.50/month**. That is roughly 4× JEV's cost for this workload, and the gap is larger with a mid-tier or frontier model. Check current prices for whichever model you compare against.

## 7. Things that could change the estimate

- **Tokenizer differences:** JEV's tokenizer may count differently from the ~4 chars/token rule. Test on a sample of 100 articles.
- **Minimums and fees:** check for minimum spend, subscription tiers, rate limits, or charges for hosting and fine-tuning.
- **Retries and re-scoring:** if you re-run articles when a dataset definition changes, add that volume.
- **Upstream costs:** crawling, text extraction and storage will probably exceed the classification cost.
- **Human review:** if flagged items go to analysts, that labor will dominate the total. The API cost is negligible next to it.

## Bottom line

For 5,000 articles/week, expect about **$1.60/month (~$20/year)** in the base case. A realistic range is **$1.20–$2.30/month** for a single dataset, rising linearly with the number of datasets checked per article.
